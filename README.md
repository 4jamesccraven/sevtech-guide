This is a simple infographic to help people navigate
[SevTech's](https://www.curseforge.com/minecraft/modpacks/sevtech-ages)
heatmap-based terrain generation.

To download a copy, see the [releases page](https://github.com/4jamesccraven/sevtech-guide/releases)

## Building
This infographic is built with [typst](https://typst.app/docs/). To build:
```bash
# PDF
typst c --font-path=./fonts -f pdf sevtech-biomes.typ

# SVG
typst c --font-path=./fonts -f svg sevtech-biomes.typ

# PNG
typst c --font-path=./fonts -f png sevtech-biomes.typ
```
